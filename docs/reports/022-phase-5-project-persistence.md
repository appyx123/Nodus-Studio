## Tujuan dan batas cakupan

- Menetapkan spesifikasi formal format penyimpanan `.nodus` v1 (`application/x-nodus-project+json`) yang mencakup topologi rangkaian (instance, koordinat world, kontrol, kabel, warna), firmware (sketch source, target FQBN), konfigurasi viewport kanvas, dan parameter bridge MQTT.
- Mengimplementasikan serialisasi dan deserialisasi atomik (`save_project_atomic`, `load_project_from_path`) di backend Rust dengan pencegahan korupsi file (`tmp` file write + atomic `rename`), batas ukuran file 10 MiB, serta sanitasi kredensial (kredensial broker tidak disimpan).
- Menyediakan mekanisme toleransi kesalahan dan pemulihan paket hilang (*missing package recovery*): rangkaian tetap dapat dimuat sebagai placeholder tanpa merusak atau menghilangkan instance/koneksi saat paket belum terpasang di registry lokal.
- Mengekspos Tauri IPC commands (`save_project`, `load_project`, `export_project_json`, `import_project_json`), mendefinisikan permission capabilities, serta mengintegrasikan UI Toolbar di frontend SolidJS.
- Batas cakupan: Logic Analyzer (Langkah 2) dan Linux packaging RPM/Flatpak (Langkah 3) belum dikerjakan.

## Keputusan teknis

- **Referensi Paket vs Embedding:** Paket komponen `.nodpkg` direferensikan berdasarkan ID dan SemVer, bukan di-embed ke dalam `.nodus`. Ini membuat ukuran file sangat hemat (< 100 KB), mempermudah pelacakan git diff, dan memastikan pembaruan logika/tampilan pada package registry otomatis dinikmati oleh proyek lama.
- **Atomic File Writing:** Penyimpanan file menggunakan penulisan ke berkas sementara di direktori target (`.<name>.tmp.<pid>`), `sync_all()`, lalu `rename` atomik sistem berkas untuk mencegah kerusakan file bila daya mati atau proses terinterupsi.
- **Penanganan Paket Hilang:** Bila suatu komponen dalam proyek tidak ditemukan di katalog registry lokal, proses load tidak gagal total (`panic`/`abort`). Komponen dimuat sebagai placeholder dengan pin pasif yang mempertahankan koordinat dan rute kabel, disertai pesan peringatan `ProjectWarning` agar pengguna tidak kehilangan pekerjaan.
