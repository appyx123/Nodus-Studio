## Tujuan dan batas cakupan

- Mengimplementasikan Digital Logic Analyzer sederhana untuk merekam dan menampilkan gelombang sinyal digital/PWM berkecepatan tinggi secara akurat.
- Memenuhi kriteria kelulusan blueprint: data sinyal dibaca dari engine Rust dengan buffer berbatas (circular buffer), bukan disimpulkan dari visual frame 60 Hz yang rentan kehilangan pulsa singkat atau mengalami aliasing pada sinyal PWM/protokol.
- Menyediakan dukungan hingga 8 kanal sinyal (CH1–CH8), penempelan probe (*probe attach/detach*) ke endpoint pin komponen, serta visualisasi bentuk gelombang digital (*digital square waveform*) di panel UI.
- Batas cakupan: Linux packaging (RPM dan Flatpak) merupakan Langkah 3 yang dikerjakan berikutnya.

## Hasil dan perubahan

- **Backend Rust (`src-tauri/`):**
  - `src-tauri/src/engine/logic_analyzer.rs`: Implementasi `LogicAnalyzer`, `LogicSample`, `ChannelSnapshot`, `LogicAnalyzerSnapshot`, `AttachProbeRequest`, serta batas kapasitas per-kanal (`MAX_SAMPLES_PER_CHANNEL = 4096`). Menyimpan timestamp `SimTime` dalam resolusi half-nanosecond ($0.5\text{ ns}$).
  - `src-tauri/src/engine/runtime.rs`: Integrasi `LogicAnalyzer` ke dalam deteksi transisi level pin `detect_edges`. Setiap perubahan level pin yang dipantau probe langsung dicatat secara deterministik tanpa terikat interval rendering.
  - `src-tauri/src/ipc/simulation_worker.rs`: Pemisahan loop worker thread simulasi dari `simulation.rs` agar ukuran file tetap ≤ 400 baris, mengintegrasikan shared `Arc<Mutex<LogicAnalyzer>>` ke runtime.
  - `src-tauri/src/ipc/simulation.rs`: Refactoring controller simulasi menggunakan `simulation_worker.rs`.
  - `src-tauri/src/ipc/commands.rs`: Penambahan command IPC `get_logic_analyzer_data`, `attach_logic_probe`, dan `detach_logic_probe`.
  - `src-tauri/src/lib.rs`: Registrasi state `Arc<Mutex<LogicAnalyzer>>` dan handler command baru.
  - `src-tauri/permissions/autogenerated/*.toml` & `src-tauri/capabilities/main.json`: Definisi hak akses command logic analyzer.
- **Frontend SolidJS & TypeScript (`src/`):**

  - `src/components/analyzer/LogicAnalyzerPanel.tsx`: Panel visual inspeksi sinyal digital dengan grafik SVG waveform, kontrol attach/detach probe ke pin terpilih, indikator status kanal, dan skala waktu (ns, µs, ms, s).
  - `src/components/canvas/WorkbenchToolbar.tsx`: Penambahan tombol toggle "Logic Analyzer".
  - `src/components/canvas/Workbench.tsx`: Integrasi panel `LogicAnalyzerPanel`.

## Keputusan teknis

- **Sampling Tingkat Event Mesin vs Frame 60 Hz:** Alih-alih melakukan *polling* terhadap visual frame 60 Hz (interval $16.6\text{ ms}$) yang dapat melewatkan pulsa PWM 500 Hz atau pulsa DHT22/UART mikrodetik, perekaman dilakukan langsung di dalam `detect_edges()` runtime pada waktu simulasi deterministik `SimTime`.
- **Circular Buffer Berbatas:** Menggunakan `VecDeque` berukuran maksimum 4.096 sampel per kanal. Ketika kapasitas tercapai, sampel tertua dikeluarkan (`pop_front()`) secara efisien $O(1)$ sehingga memori aplikasi tetap berbatas dan stabil.
- **Pemisahan Modul Worker:** Mengabstraksikan loop OS thread `run_thread` ke `simulation_worker.rs` agar `simulation.rs` tetap patuh pada batas maksimal 400 baris kode per file.
